# Core Operation Rates — transcribed from image

**Source:** `https://autoclusterpune.org/wp-content/uploads/2025/10/Core-Operation-Rates-1.jpg`
(1042 × 1066 px JPEG, the only pricing published anywhere on the site)

**Why this file exists.** The audit flagged this as a 🔴 defect: the rate data is not readable
by search engines, not readable by screen readers, not selectable, not printable as text and
not responsive on mobile. Transcribed here so it can be built as an HTML table at
`/venues/rate-card` plus a per-machine rate line on each `/equipment/[slug]` page, with the
original JPEG retained only as a downloadable PDF.

## What this document reveals that the rest of the site does not

The rate card is the only source for several facts, and it corroborates or contradicts others.
All are logged in `CONTENT_QUESTIONS.md`.

| Finding | Effect |
|---|---|
| **Hot Air Oven** is a billable RPL machine | Absent from the 30-machine catalogue entirely (CQ-51) |
| **Mini Salt Spray Chamber** is billable | Named in Environmental page copy but never catalogued — confirms it is real (CQ-51) |
| **Figure 4 – Standalone Pro** and **Origin 1 SLA** are billable 3D printers | The Rapid Prototyping page lists only four machines; these two appear nowhere (CQ-52) |
| Rates list **5 Axis Machining** and **3 + 1 Axis** | Independently corroborates the PPF machine cards and contradicts the page's "3 Axis, 4 axis, and 3+2 Axis" capability claim (CQ-02) |
| Spelt **QUV Weather-O-Meter** | Confirms `Whethr-O-meter` on the RPL page is a typo (CQ-17) |
| Two-tier MSME / OEM pricing with an MCCIA member discount | A genuine commercial differentiator that appears nowhere in the site's copy |
| No venue-hire rates | Exhibition Centre, Auditorium and Training Hall have no published pricing at all (CQ-58) |
